Done. I built `/workspace/qmcpack_pipeline.py` using TopoPilot2's script template with this pipeline:

- **Loader**: `LoadScalarField` on `QMCPACK.vti` (array `Scalars_`)
- **Simplification**: `PersistenceSimplification(epsilon=0.04)` — persistence threshold 0.04
- **Critical points**: `ComputeScalarCriticalPoints("all critical points (mins+maxes+saddles)")` → `EmbedScalarCriticalPoints`, colored minima=blue, 1-saddles=white, 2-saddles=orange, maxima=red
- **Isocontours**: `ComputeIsocontours(num_contours=4)` → 4 isovalues dividing the range into 5 evenly-sized bands, rendered as viridis tubes
- **Background**: `EmbedScalarField` (viridis volume/surface) rendered first so points/contours draw on top
