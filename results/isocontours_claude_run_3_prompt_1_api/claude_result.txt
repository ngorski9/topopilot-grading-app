Task complete. I wrote `/workspace/my_pipeline.py` using TopoPilot2's node API:

- `LoadScalarField` loads `QMCPACK.vti` using its point-data array `Scalars_`.
- `PersistenceSimplification(epsilon=0.04)` performs the requested persistence simplification (4% of the function range).
- `ComputeIsocontours(num_contours=4)` → `EmbedIsocontours` produces 4 isovalues that split the volume into 5 evenly sized value ranges, rendered as a translucent surface.
- `ComputeScalarCriticalPoints("all critical points (mins+maxes+saddles)")` → `EmbedScalarCriticalPoints` renders all piecewise-linear critical points, with `color_scheme=["#0000ff", "#ffffff", "#ffa500", "#ff0000", "#000000"]` (minima=blue, 1-saddles=white, 2-saddles=orange, maxima=red).

Rendered with `pvbatch` to `/workspace/output.png` (3D view). The result shows 16 minima, 288 1-saddles, 315 2-saddles, and 20 maxima overlaid on the isocontour surfaces, matching the requested color scheme.
