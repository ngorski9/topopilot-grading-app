It loads the raw `Scalars_` field with viridis, simplifies at persistence threshold `0.1`, and overlays the piecewise-linear contour tree with radius-1 edges and radius-2 vertices. Colors are minima blue, 1-saddles white, 2-saddles orange, and maxima red.
