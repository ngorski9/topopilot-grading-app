Pipeline built at `/workspace/cloud_pipeline.py`:

- `LoadScalarField` on `./cloud3step` (a 3-step copy of the first 3 frames of `./cloud`, array `Scalars_`)
- `EmbedScalarField` (cool warm colormap) — the original field render
- `PersistenceSimplification(epsilon=0.5)` → `ComputeScalarCriticalPoints("maxima")` → `TrackScalarCriticalPoints(time_steps=3, backend="emd")` → `EmbedTrackedScalarFieldCriticalPoints(radius=2.0)`
